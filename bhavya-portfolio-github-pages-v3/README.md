# Bhavya — Personal Portfolio

A small interactive personal website designed for GitHub Pages.

## Run locally

Just open `index.html` in a browser.

For a local server (recommended):

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Put it on GitHub Pages

1. Create a GitHub repository, for example `bhavya-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your Pages URL.

## Before publishing

Search `YOUR_` in `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`

You can also replace the placeholder project descriptions and add images inside `assets/`.
