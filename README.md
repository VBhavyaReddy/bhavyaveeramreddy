# Bhavya — Little Corner of the Internet

A small interactive portfolio / personal universe for GitHub Pages.

## V10 additions
- Photography added as an eighth constellation interest.
- A dedicated camera-roll section with ready-to-fill personal photo slots.
- Known socials integrated into the contact section.
- Autonomous Rover and PID reports now render inside their project modals in scrollable PDF frames.
- PID project video rendering tightened for the project modal and smaller screens.

## GitHub Pages
Upload the contents of this folder to the repository root, including the `assets` folder.

Personal photos can be added later under `assets/photos/` and the photo slots in `index.html` can then be pointed at those files.
